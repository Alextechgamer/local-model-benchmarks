STAGE 1 of 5 - engine and ground. Create pagoda.html with:
- Renderer (antialias, ACESFilmicToneMapping, sRGB output, PCFSoft shadow map enabled), scene, perspective camera, OrbitControls with damping, min/max distance and a polar-angle limit so the camera never goes below ground, window-resize handling, requestAnimationFrame loop using a THREE.Clock delta.
- A seeded pseudo-random generator (e.g. mulberry32) with a `seed` variable, so the garden is identical on every load.
- A voxel builder: voxels collected as {x, y, z, colorHex} in a Map keyed by "x,y,z" so overlapping voxels dedupe, plus an `emissive` flag. Helpers box, fillRect, cylinder, sphere. A build step that turns the map into THREE.InstancedMesh objects (one shared BoxGeometry, per-instance colour via setColorAt, a slight +-4% lightness jitter per voxel): ONE InstancedMesh for opaque voxels and ONE for emissive voxels (MeshBasic or emissive material). Never one Mesh per cube. Voxel size 1.
- buildTerrain: a roughly 80x80 unit garden, gently rolling ground (height 0-3 from smooth noise) with grass, dirt and gravel patches, a small hill near the centre where the pagoda will stand, a raked-sand zen area (pale sand with darker raked stripes), and a stone path from the south edge (where the torii gate will be) to the hill. Keep terrain to roughly 7,500 voxels (only the visible top layer plus an edge skirt, not a solid block).
- A simple directional light + hemisphere light for now, a sky-blue background, and a small fixed readout in a corner showing the voxel count (also console.log it).
A function `buildGarden()` must clear and rebuild everything from the seed (dispose old InstancedMeshes), because a later stage adds a "Regenerate seed" button.
